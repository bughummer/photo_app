# Photo Flow Studio

An early desktop prototype for moving the colors of an existing image. It deliberately does not turn photos into paintings.

## Run

Install Node.js 20 or newer, then run `npm install` and `npm start` to open the Electron desktop app. For a browser preview, run `npm run web` and visit `http://127.0.0.1:4173`.

Open a JPG, PNG, or WebP image. Drag across it with a mouse or finger using Fluid smear, Swirl, Bulge, Disperse, Paint pull, Water lens, Smoke, Particle bloom, Fragment field, Wind trails, Painterly dissolve, Digital glitch, or Mirror distortion. Each brush has a small illustrated preview beside its name. Paint pull draws broad directional patches with broken edges from the image's existing colors. Water lens bends the image into ripples and adds subtle color separation. Smoke drags source colors into soft wisps. Particle bloom lifts dense, glowing fibers while gently dimming the brushed image beneath them. Fragment field lifts small image shards into gold dust and has an optional perspective grid. Wind trails stretches colors and draws fine image-colored strands along the drag direction, with soft blur and slight color separation; turn on Warm glow before painting to add light around bright edges and strands. Painterly dissolve pulls image colors into layered, rough edged marks while breaking up the area beneath. Digital glitch shifts blocks of pixels, breaks scanlines, and separates color channels within the brush area. Mirror distortion folds nearby image details into uneven vertical reflections, like warped glass panels. For the layered effects, a source image with a dark background and a clear subject works best. Adjust brush size and strength. Keep moving lets strokes, fibers, fragments, and paint marks continue briefly after release; switch it off to stop at release. Undo, Reset image, and Export PNG are available.

## Brush shapes

Choose **Generate brush** to make a random shape. Complexity changes how many lobes its outline has, Roughness changes how far they protrude, Texture adds translucent gaps, and Soft edge smooths the boundary. Edit the Seed to reproduce a variation, or choose **New variation** for a new seed. Adjusting a control updates an active generated brush. **Import PNG brush** still turns a PNG into a shape: transparent PNGs use alpha by default, and opaque PNGs use dark pixels by default. Change **Use image** to select transparency, dark areas, or light areas. Either shape works with every movement effect. **Save brush PNG** exports the active shape; **Use round** restores the built-in brush. Brush shapes stay local to the running app, so save one as a PNG to reuse it later. Photoshop `.abr` files are not supported.

Images are processed locally. Fragment field and Particle bloom are layered 2D effects inspired by the reference images; they do not reconstruct 3D geometry. The working image is capped at 1800 pixels on its longest side for interactive performance, so exported PNGs use that working resolution. Animation export is not part of this prototype.
